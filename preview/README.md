# BQ Sqwad AI Acode Preview

Open `preview/index.html` in Acode and tap Preview/Run. If Acode blocks scripts, open the file in the phone browser from the same folder.

This is an offline HTML/CSS/JS mock of the native Android app. It does not run Kotlin or Jetpack Compose and does not replace the debug APK for final device testing.

The preview contains mock states for Auth/Consent, Main Chat, History, Settings, Learning Studio, Companion, TruthGuard, Video Generation, Business Workspace, Organization Studio, Product Catalog, Legal Center, Admin Control Surface and Account Protection. Use the state buttons to inspect loading, empty, error and success states.

No API keys, Firebase service accounts, access tokens or signing material belong in this folder. The optional Live /health button only calls the public Worker health endpoint.
