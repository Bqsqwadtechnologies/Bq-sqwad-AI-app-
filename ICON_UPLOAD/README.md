# Upload the new BQ Sqwad AI icon artwork here

Please upload your white-background logo image into this folder using GitHub's **Add file → Upload files** option.

## What to upload

- The new white-background logo image you want used for the Android launcher icon and notification artwork.
- Preferred format: PNG, ideally a square image with the logo centered and some padding around it. JPG is also acceptable for the source artwork.
- Suggested filename: `bq-icon-white-background.png`

## Important

This folder is only a safe staging area for the source image. Do not replace `app/src/main/res/drawable-nodpi/bq_sqwad_logo.jpg` or any existing app resource. The in-app logo must remain unchanged. After you upload the image, tell ChatGPT and the source image can be checked and applied only to the launcher and supported notification icon resources.
