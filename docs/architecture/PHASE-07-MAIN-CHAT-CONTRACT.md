# Phase 7 — Main Chat Intelligence
## Objective
Create a fast, dedicated Main Chat workspace. It is not the container for every other product.
## UX
- Fast non-streaming response presentation.
- Text input.
- Voice-to-text input.
- Optional spoken AI response.
- Copy, share, resend, and report compact actions.
- Image generation entry.
- Separate video mode entry.
- Conversation history.
## Boundaries
Main Chat can request Web Search or another dedicated workspace when needed, but Camera, Live Voice, Business, Learning, Life Matters, and other major features remain separate workspaces.
## Backend contract
Model/provider, pricing, credits, moderation, search escalation, and entitlement decisions are server controlled.
## Acceptance
No fake streaming animation, fake generation progress, or fake provider response is presented as real work.
