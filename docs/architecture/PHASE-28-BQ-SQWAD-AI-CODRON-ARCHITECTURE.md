# Phase 28 — BQ Sqwad AI Intelligence / Codron Architecture
## Objective
Reserve a plugin-style architecture for BQ Sqwad AI Agent and future BQ Sqwad Codron.
## Plugin contract
- Manifest.
- Version.
- Capabilities.
- Required permissions.
- Entitlements.
- Provider dependencies.
- Activation state.
- Admin controls.
- UI entry points.
## Rule
Codron is a future plugin capability, not a fake feature or placeholder button.
## Acceptance
A plugin can be activated/deactivated remotely without coupling its implementation to Main Chat.
