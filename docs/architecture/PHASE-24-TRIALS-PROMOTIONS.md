# Phase 24 — Trials & Promotions
## Objective
Support remote-controlled trials, coupons/promotions, referral rewards, and introductory entitlements.
## Rules
Eligibility is server-side. The client only displays the resulting eligibility and terms.
## Audit
Every promotional entitlement has source, start, end, and adjustment/revocation metadata.
## Acceptance
Admin can disable a promotion without an APK release.
