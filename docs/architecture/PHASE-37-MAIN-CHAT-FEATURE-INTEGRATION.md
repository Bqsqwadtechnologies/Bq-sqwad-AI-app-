# Phase 37 — Main Chat & Feature Integration
## Objective
Define controlled cross-workspace handoffs.
## Examples
- Main Chat -> Web Search.
- Main Chat -> image generation.
- Main Chat -> video mode.
- Camera -> Web Search.
- Live Voice -> Web Search.
- Business agent -> approved business tools.
## Rule
Handoff preserves context only when the user and feature contract allow it. It does not merge all features into one screen.
## Acceptance
Every handoff has a visible destination and a recoverable failure path.
