# Phase 8 — Web Search Intelligence
## Objective
Define a dedicated Web Search workspace and a callable search capability for eligible AI surfaces.
## Workspace
- Search box.
- Current-query state.
- Source/result presentation.
- Search history where enabled.
- Credit/usage visibility.
- Error and no-result states.
## Cross-feature invocation
Main Chat, Live Camera, and Live Voice may request current information through a shared search contract. The user remains informed when external search is used.
## Pricing
Search credit cost is remote/admin controlled. No hardcoded commercial amount is authoritative in the Android client.
## Acceptance
Search can be enabled, disabled, repriced, or provider-routed without shipping a new APK.
