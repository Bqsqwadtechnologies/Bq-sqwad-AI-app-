# Phase 33 — Referral System
## Objective
Support referral codes and rewards through a server-authoritative flow.
## Flow
Invite/code -> attribution -> eligibility -> reward decision -> ledger entry -> receipt/history.
## Rules
Rewards cannot be granted solely from a client-side code entry. Fraud/duplicate attribution checks belong server-side.
## Acceptance
Referral status is visible to the user and auditable by Admin.
