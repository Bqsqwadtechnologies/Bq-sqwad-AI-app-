# Phase 19 — Business Plans & Plan Builder
## Objective
Make Business limits and features catalog-driven.
## Existing reference
The old repository contains tier identifiers including starter, basic, standard, professional, premium/super-premium, and enterprise variants. The native app must not invent or freeze commercial names; the server catalog is authoritative.
## Plan builder
Admin can configure:
- Feature entitlements.
- Agent/workspace limits.
- Usage limits.
- Channel limits.
- Automation limits.
- Pricing display.
- Trial eligibility.
- Visibility.
- Enterprise/custom status.
## Acceptance
Plan changes are data/config changes, not Android code changes.
