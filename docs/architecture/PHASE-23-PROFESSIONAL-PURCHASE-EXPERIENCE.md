# Phase 23 — Professional Purchase Experience
## UX
- Catalog browsing.
- Product details.
- Current entitlement.
- Checkout.
- Processing state.
- Success/failure/pending state.
- Receipt.
- Credit/entitlement refresh.
## Requirements
Purchases remain polished in-app. A website handoff is only used when required by the selected provider or policy, and the app must recover correctly after return.
## Acceptance
The UI never grants credits merely because a payment screen was opened.
