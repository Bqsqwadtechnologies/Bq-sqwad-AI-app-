# Phase 16 — Business Agents
## Objective
Define plan-controlled business agents.
## Agent model
Each agent has:
- Purpose.
- Instructions.
- Knowledge.
- Tools.
- Channels.
- Permissions.
- Training/reference data.
- Usage and analytics.
## Limits
Agent/workspace limits come from the active plan configuration. Do not hard-code a fixed number such as three or ten.
## Acceptance
Creating, editing, enabling, disabling, and deleting an agent are real backend operations with entitlement checks.
