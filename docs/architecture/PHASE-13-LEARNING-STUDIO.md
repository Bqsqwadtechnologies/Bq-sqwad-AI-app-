# Phase 13 — Learning Intelligence Studio
## Objective
Build a dedicated learning environment.
## Required areas
- Subjects.
- Custom subjects.
- User-created topics.
- Lessons.
- Learning history.
- Voice teaching.
- Progress.
- Entitlement/usage.
## Architecture
Lesson generation, subject catalog, limits, pricing, and model routing are backend-controlled.
## Acceptance
A user can create a custom learning topic without changing the global app navigation or hard-coding a new screen.
