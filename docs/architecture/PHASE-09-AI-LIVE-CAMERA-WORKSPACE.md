# Phase 9 — AI Live Camera Workspace
## Objective
A dedicated native camera intelligence workspace, separate from Main Chat.
## Capabilities
- Camera preview/capture.
- Visual questions.
- Object/scene understanding.
- Real-time assistant interaction.
- Voice direction.
- AI speaking mute.
- Microphone mute.
- Voice selection.
- Location-assisted tasks when explicitly permitted.
- Device actions through a permissioned command layer.
- Social live-streaming entry point without a cluttered platform list.
## Screen awareness
Android screen capture uses MediaProjection with explicit user consent. The app must not silently capture or infer that consent exists forever.
## Acceptance
Camera, microphone, location, and screen capture permissions are independently controlled and clearly surfaced.
